## Descripción del problema
En una tienda se necesita calcular el total de una compra según el precio
de un producto y la cantidad que lleva el cliente. Este programa resuelve
el problema mediante una función en Python que recibe ambos datos como
parámetros, realiza la multiplicación y devuelve el resultado.

## Cómo funciona
El programa define la función `calcular_total(precio, cantidad)`, que:
1. Recibe dos parámetros: el precio unitario y la cantidad de unidades.
2. Realiza el cálculo `total = precio * cantidad`.
3. Retorna el resultado con `return`.

Luego, desde el bloque principal (`if __name__ == "__main__":`), se llama
a la función con valores de ejemplo y se muestra el total en consola con
`print()`.
